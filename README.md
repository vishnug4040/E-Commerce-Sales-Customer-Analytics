# E-Commerce Sales & Customer Analytics

## Project Overview

This project focuses on analyzing e-commerce business data using **Excel, Python, MySQL, and Power BI**. The objective is to transform raw data into meaningful business insights by examining sales performance, customer behavior, product performance, payment methods, returns, shipping, and inventory.

The project demonstrates an end-to-end data analytics workflow, from data inspection and cleaning to SQL-based analysis and interactive dashboard development.

## Project Objectives

* Analyze overall sales performance and revenue trends.
* Identify top-performing products and product categories.
* Understand customer distribution and sales performance by state.
* Analyze monthly and yearly sales trends.
* Examine payment method distribution.
* Investigate product returns and refund amounts.
* Evaluate shipping performance across carriers.
* Identify products requiring inventory replenishment.
* Analyze customer product ratings and reviews.

## Tools & Technologies

* **Microsoft Excel:** Data storage and initial data preparation.
* **Python:** Data cleaning, transformation, analysis, and visualization.
* **Pandas:** Data manipulation and analysis.
* **Matplotlib:** Data visualization.
* **MySQL:** Relational database management and SQL analysis.
* **SQLAlchemy & PyMySQL:** Python-to-MySQL connectivity.
* **Power BI:** Interactive dashboard development and business reporting.

## Dataset Overview

The project uses 10 related datasets:

1. Customers
2. Orders
3. Sales
4. Products
5. Returns
6. Inventory

8. Reviews
9. Shipping
10. Suppliers

These datasets support analysis across customers, orders, products, transactions, and business operations.

## Project Workflow

### 1. Excel — Data Preparation

* Organized the business data into separate datasets.
* Prepared the files for analysis using Python.
* Used the datasets as the starting point for the analytics workflow.

### 2. Python — Data Cleaning & Analysis

Used Python and Pandas to inspect datasets, check missing values, identify duplicate records, combine related datasets, and perform business analysis.

Key analysis areas included:

* Sales by product category.
* Top 10 products by sales.
* Sales by state.
* Orders by state.
* Monthly and yearly sales trends.
* Customer order counts.
* Payment method distribution.
* Return reasons and refund amounts.
* Average delivery time by shipping carrier.
* Average product ratings.
* Product profit and profit margin calculations.

### 3. MySQL — Database Management & SQL Analysis

Created an `E_commerce` database and worked with primary keys and foreign keys to establish relationships between the datasets.

SQL was used to analyze:

* Total sales and order counts.
* Product ratings.
* Orders by sales channel.
* Average order value by state.
* Products with stock at or below their reorder level.
* Sales by product category and state.
* Yearly sales performance.
* The year with the highest sales.

### 4. Power BI — Interactive Dashboard

Used Power BI to develop a business dashboard for presenting and exploring e-commerce performance.

The dashboard is intended to make important business metrics and trends easier to understand. Refer to the included Power BI file and screenshots for the actual dashboard visuals.
